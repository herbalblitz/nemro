# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |

## Reporting a vulnerability

Please do **not** open a public issue for a security or privacy vulnerability.

Use GitHub's private vulnerability reporting:

1. Open the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Include the affected version, steps to reproduce, and the impact.

If private reporting is unavailable, contact the maintainer through GitHub and ask for a private channel before sharing details.

## Scope

Nemro is a local-first educational app. Security and privacy issues include, but are not limited to:

- unintended network access or data collection;
- camera frames being stored or transmitted;
- permission requests that are broader than necessary;
- unsafe handling of local session data;
- misleading claims that create a medical or privacy risk.

## What to expect

- Acknowledgment within a reasonable time.
- A fix or mitigation plan for confirmed issues.
- Credit in the changelog if you want it.

Nemro is not a medical device. Do not use it for diagnosis, treatment, or emergency decisions.
